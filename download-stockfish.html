🚀 Setup Stockfish for Your Chess Game

To enable AI opponent and game analysis features, you need to set up the Stockfish chess engine. Follow these simple steps:

📥 Quick Setup (Recommended)

Step 1: Download Stockfish.js

Click one of these download links:

⬇️ Download Stockfish.js ⬇️ Download Stockfish WASM (Faster)

Note: WASM version is faster but requires both .js and .wasm files

Step 2: Place the File

Move the downloaded file to the same folder as your chess.html file:

📁 Desktop/chs/ ├── chess.html ├── stockfish.js ← Place here └── README.md
Step 3: Update chess.html

Open chess.html in a text editor and find line ~1039:

stockfish = new Worker('https://cdn.jsdelivr.net/npm/stockfish.js@10.0.2/stockfish.js');

Replace it with:

stockfish = new Worker('stockfish.js');

Also update line ~1070 (in the tryAlternativeStockfish function) the same way.

Step 4: Run with Local Server

Due to browser security, you need to run the file through a local server:

Option A - Python (if installed):

# Open terminal/command prompt in the chs folder cd Desktop/chs # Python 3 python -m http.server 8000 # Python 2 python -m SimpleHTTPServer 8000

Option B - Node.js (if installed):

# Install http-server globally (once) npm install -g http-server # Run server cd Desktop/chs http-server -p 8000

Option C - VS Code:

Install "Live Server" extension and right-click chess.html → "Open with Live Server"

Step 5: Open in Browser

Navigate to: http://localhost:8000/chess.html

The engine status should show "Engine: Ready" in green!

✅ Success!

You can now:

  • Play against Stockfish AI
  • Analyze your games
  • Get move classifications (Brilliant, Great, Best, etc.)
  • See position evaluations

🔧 Alternative: Manual Download

If automatic download doesn't work:
  1. Visit: https://github.com/nmrugg/stockfish.js/releases
  2. Find version 10.0.2 or latest
  3. Download stockfish.js or stockfish.wasm.js
  4. Follow steps 2-5 above

❓ Troubleshooting

⚠️ "Engine: Not available" error?
  • Make sure stockfish.js is in the same folder as chess.html
  • Verify you're using a local server (not file:// protocol)
  • Check browser console (F12) for specific errors
  • Try a different browser (Chrome recommended)
  • Ensure JavaScript is enabled
⚠️ CORS errors?

This means you're opening the file directly (file:// protocol). You MUST use a local server as described in Step 4.

🎮 Ready to Play!

Once setup is complete, enjoy your chess game with full AI and analysis features!
